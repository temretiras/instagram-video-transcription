## 📌 Videoda Bahsedilen 5 Temel Araç Özeti

1. **Taste Skill:** Claude'a estetik vizyon kazandıran, klişe AI degradeleri yerine minimalist ve modern tasarım dili öğreten yetenek.
2. **Web Design Guidelines:** Kodlanan arayüzü responsive kurallara, kontrast oranlarına ve UI standartlarına göre denetleyen (audit) araç.
3. **Awesome Design:** Claude'un doğru renk, tipografi, grid ve spacing sistemini referans almasını sağlayan tasarım kütüphanesi.
4. **Image to Code:** Beğenilen ekran görüntüsünü doğrudan temiz React/Tailwind koduna dönüştürme yöntemi.
5. **Playwright CLI / MCP:** Claude'un tarayıcıyı kendi açıp ekran görüntüsü alarak kodladığı UI'ı doğrulaması.
